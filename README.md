## 🚀 What I'm Building

### [🛡️ Shield by Vouch](https://github.com/priyamdeepanshu-a11y/shield-by-vouch)

**Lock your AI chatbot to its business. Nothing else.**

- Blocks off-topic queries before they hit your LLM — saves API money
- Stops prompt injection & identity leaks instantly
- Works with any AI provider: OpenAI, Groq, Gemini, Anthropic, OpenRouter
- Auto-healing backend — model deprecated? System auto-switches
- Zero cost · MIT License · 3-layer protection

**[Live Demo](https://shield-by-vouch.vercel.app) · [Documentation](https://github.com/priyamdeepanshu-a11y/shield-by-vouch#readme)**
